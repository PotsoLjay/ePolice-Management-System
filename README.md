# ePolice Management System

A web-based Police Case Management System developed to replace manual case recording with a digital solution. The system improves case management by securely storing police records, assigning cases to officers, and providing an organized platform for managing investigations.

## Overview

The ePolice Management System was developed to address the challenges associated with paper-based police case management, such as lost dockets, inefficient record keeping, and manual assignment of cases.

The application provides a centralized platform where police personnel can manage cases more efficiently while improving data accessibility and organization.

## Features

- Secure user authentication
- Officer registration and management
- Digital case recording
- Case assignment to police officers
- Centralized case information storage
- SQL Server database integration
- User-friendly web interface

## Installation

1. Clone the repository.

```bash
git clone https://github.com/PotsoLjay/ePolice-Management-System.git
```

2. Open the solution in Visual Studio.

3. Restore the required NuGet packages.

4. Create the database using the provided `Project.sql` script.

5. Update the SQL Server connection string in `Web.config` if necessary.

6. Run the application.
